# Phase 07 — Frontend Bootstrap

> Read `00-index.md` first. Commit after each task.

**Goal:** Set up the React SPA scaffolding: Vite 8, React 19, TypeScript 6, Tailwind v4 (CSS-first config), shadcn (CLI-managed copies of components), TanStack Router (file-based) + TanStack Query, Biome 2 for lint+format, base layout with top nav + theme toggle, and the global keyboard shortcut wiring. Stub each future feature route so subsequent phases just fill them in.

**Dependencies:** None — fully parallelizable with all Go phases.

**Tech stack (versions confirmed 2026-05-21):**
- Vite **8.x** (Rolldown bundler; ~10–30× faster builds vs v5)
- React **19.x** + ReactDOM 19 (no `forwardRef`; ref as regular prop)
- TypeScript **6.x**
- Tailwind CSS **v4.x** via `@tailwindcss/vite` plugin (no `tailwind.config.ts`, no PostCSS pipeline)
- shadcn **4.x** CLI (package is `shadcn`, not `shadcn-ui`)
- TanStack Router **v1** with file-based routing via `@tanstack/router-plugin`
- TanStack Query **v5**
- react-hook-form 7 + zod **v4** + @hookform/resolvers **v5**
- date-fns 4 (ESM-only), lucide-react 1
- Biome **v2**
- Vitest **v4** + Testing Library 16 + jsdom 29
- pnpm

> **Doc reference:** Tailwind v4 is a major rewrite vs v3 and shadcn 4 ships a v4-native template. If any CLI flag has shifted since 2026-05-21, use the **find-docs** / **context7** skill to fetch current shadcn / Tailwind / TanStack Router docs before executing.

**Parallelizable with:** Anything.

## Task 2: Tailwind v4 (CSS-first, Vite plugin)

Tailwind v4 has no JS config file and no PostCSS pipeline. The config lives in CSS via `@theme {}`; the Vite plugin handles everything else (Lightning CSS, autoprefixing, content scanning).

- [ ] Install:
  ```bash
  cd web && pnpm add -D tailwindcss@^4 @tailwindcss/vite@^4
  ```
- [ ] Update `vite.config.ts` to include the Tailwind plugin:
  ```ts
  import { defineConfig } from 'vite';
  import react from '@vitejs/plugin-react';
  import tailwindcss from '@tailwindcss/vite';

  export default defineConfig({
    plugins: [tailwindcss(), react()],
    server: { proxy: { '/api': 'http://localhost:8080' } },
  });
  ```
  (Order matters once we add the router plugin in Task 4: `tanstackRouter()` must come **before** `react()`.)
- [ ] Replace `web/src/index.css` (rename to `src/styles.css`) with:

  ```css
     it appends the @theme block + light/dark CSS variable layers here. */
  ```
- [ ] Update `src/main.tsx` to `import './styles.css'`.
- [ ] Delete any leftover `postcss.config.*` or `autoprefixer` deps if `pnpm create vite` produced them — Tailwind v4 doesn't need them.

## Task 7: Global keyboard shortcuts

**Files:** `web/src/lib/shortcuts.ts`, `web/src/components/shortcut-cheatsheet.tsx`

Per spec §6:
- Global: `n` new task, `/` focus search (navigates to `/tasks` first if elsewhere), `g {t,s,c,g,r}` for nav, `?` toggle cheatsheet.
- Per-page handlers are registered by individual pages in 08x; this phase only wires the global ones.

- [ ] Implement `useGlobalShortcuts(router)`:
  - Tracks the `g`-leader chord with a 1000ms timeout.
  - Ignores keystrokes when focus is on `<input>`, `<textarea>`, or `[contenteditable]`.
  - `n`: dispatch `CustomEvent('tt:new-task')` on `window`; pages listen.
  - `g t/s/c/g/r`: `router.navigate({to: '/tasks'})` etc.
  - `/`: focus `document.querySelector<HTMLInputElement>('[data-search-input]')`; if not present, navigate to `/tasks` then focus on next tick.
  - `?`: dispatch `tt:toggle-cheatsheet`.
- [ ] `<ShortcutCheatsheet />` is a shadcn `<Dialog>` listing all shortcuts from spec §6.
- [ ] Wire `useGlobalShortcuts` in `__root.tsx`.
- [ ] Commit:
  ```bash
  git add web/src/lib/shortcuts.ts web/src/components/shortcut-cheatsheet.tsx && \
    git commit -m "feat(web): add global keyboard shortcuts and cheatsheet"
  ```
